# 1g1g Revival — 开发进度

> 规范要求见需求文档第十五节。本文档按 Phase 记录实际完成情况，所有条目均已实际运行验证，未实现的绝未标记为完成。

## Phase 0：项目分析 — ✅ 完成

- 产出 `docs/PROJECT_ANALYSIS.md`：分析 `cypggs/mygo-web-cloudmusic` 的双通道（公开 API + EAPI 加密）网易云实现，确定复用方案。
- 产出 `docs/DECISIONS.md`：D1 技术栈（Vite+React 18+TS+Zustand / 零依赖 Node http / node:sqlite）、D2 音乐来源合规政策、D3 认证方案（scrypt + HttpOnly Cookie）、D4 视觉基准（考古采样色值）、D5 历史功能取舍。

## Phase 1：界面骨架 — ✅ 完成

- 五分区布局还原：用户区（TopBar）、栏目区（NavBar）、播放区（PlayerWidget）、浏览区（BrowserPanel）、信息区（InfoBar）。
- 欢迎页使用原版文案；「开始亦歌之旅」按钮进入主界面。
- 5 套主题（淡蓝/红/蓝/黑/Google 色）CSS 变量实现，顶栏色板即时切换，登录用户持久化到服务端。
- 响应式：1060px 以下隐藏浏览区，620px 以下移动布局。

## Phase 2：播放核心 — ✅ 完成

- HTML5 Audio 引擎：loadSeq 竞态守卫、MediaSession 集成、浏览器标题同步「歌 - 歌手 | 亦歌」。
- 播放列表规则全部实现并逐项用 `window.__1g1g` 自动化验证：
  - 始终从列表第一首开始播放；
  - 锁定歌曲播完轮到底部，未锁定歌曲播完移除；
  - 列表自动从推荐补满（上限默认 30，首载 20，可设置 5-100）；
  - 浏览区选歌插入**第二位**（localStorage 状态 diff 验证）；
  - 播放模式：全部 / 仅锁定 / 单曲循环；
  - 双击下一首 = 重新解析播放源（260ms 单击/双击判别）；
  - 悬停行显示 ▶🔒★✕。
- 键盘快捷键 t/f/h/p/n/m，输入框聚焦时自动失效。
- 修复：`advanceQueue` 缺少 `set({ songs })` 导致队列状态不更新的 bug（已回归验证）。

## Phase 3：网易云接入 — ✅ 完成

- 复用 mygo 已验证实现：`server/netease.mjs`（EAPI AES-128-ECB 加密、iPhone UA、TTL 缓存）。
- `server/provider.mjs`：搜索（cloudsearch）、批量可播放性校验（`url && size && !freeTrialInfo` 三条件）、歌词、评论、榜单。
- VIP/版权歌曲**绝不进队列**：/api/bootstrap、/api/chart、/api/lucky、/api/refill 全部走验证池；搜索/榜单结果中不可播放项置灰 + 删除线 + VIP 标记，播放/加入按钮隐藏。
- 实测：Taylor Swift《Love Story》10 个版本全部正确标记不可播放；周杰伦歌曲可正常播放。

## Phase 4：收藏与历史 — ✅ 完成

- 注册/登录（邮箱+密码，scrypt 哈希，HttpOnly Cookie 会话 30 天）。
- 收藏：增删改查、附注（✎）、搜索过滤（歌名/歌手/专辑/附注）、分页（每页 13）；搜索结果中收藏置顶。
- 收藏跨设备（服务端），锁定仅本地（localStorage）——与原版语义一致。
- 刚刚听过：登录用户按账号、匿名用户按 X-Device-Id 记录播放时长与完成度，面板倒序展示（已验证 6 条真实记录）。
- 分享直链：`/歌手+歌曲名` 自动搜索并播放。修复了 insert 后 `playAt(0)` 不生效的逻辑错误（应为 `playAt(1)`），已实测 `/周杰伦+晴天` 直达播放。

## Phase 5：推荐系统 — ✅ 完成

- 信号权重：收藏 +10 / 锁定 +8 / 完整听完 +2 / 听 60% 以上 +1 / 跳过 -3 / 听不足 20% -5 / 取消收藏 -5 / 解锁 -1 / 黑名单歌手 -100。
- 用户画像：7 天近期 vs 长期歌手得分、近期已听歌曲去重、黑名单过滤（候选直接 -Infinity）。
- 多样性配额：50% 偏好歌手 / 20% 中性 / 30% 惊喜。
- 「手气不错」：每首歌给出诚实推荐理由（「你收藏过 X 的歌」仅在确实收藏时给出，否则「与你最近的偏好相似」/「一首你可能没听过的歌」）。
- 黑名单：信息区一键拉黑歌手，设置面板可管理/解除。

## Phase 6：辅助功能 — ✅ 完成

- 歌词浮窗：同步滚动高亮、点击行校准进度、拖拽/缩放、位置记忆（localStorage）。修复了条件 return 导致的 hooks 顺序崩溃（React #310）。
- 歌曲评论：右侧竖排 tab 拉出面板，真实网易云评论（点赞数/时间）。
- MV：跳转 B 站搜索（仅外部合法来源）；下载：跳转 163 搜索。
- 报告链接错误：信息区弹窗选择类型写入 `playback_reports` 表。
- 学唱：轻量跟唱模式占位（D5 决策：原版学唱功能依赖已失传的服务端，以诚实降级实现）。
- 亦歌吧：外链占位。
